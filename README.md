# **Sales Analysis Dashboard – Excel Project**  

## **Project Overview**  
This project presents a **Sales Analysis Dashboard** built in **Excel**, designed to provide key business insights into sales performance. The dashboard includes metrics such as **total revenue, top-selling products, regional performance, sales trends, and customer purchasing behavior** to support data-driven decision-making.  

The project leverages **advanced Excel functionalities** like Power Query Editor, Power Pivot, Pivot Tables etc to clean, model, and visualize data interactively, demonstrating how Excel can be used for business intelligence and reporting.  

---

## **Key Features and Tools Used**  

- **Power Query Editor** – Cleaned, transformed, and merged multiple datasets.  
- **Power Pivot and Data Model** – Established relationships between datasets for efficient data analysis.  
- **DAX Functions and Measures** – Created calculated fields such as **Total Revenue, Average Spend, and Delivery Days** for advanced analytics.  
- **Pivot Tables and Pivot Charts** – Summarized and visualized key sales trends.  
- **Slicers and Timelines** – Enabled interactive filtering by **Order Date, Occasion, and Delivery Date** for dynamic data exploration.

## **How to Use the Dashboard**  

1. **Download the Excel file** from this repository.  
2. Open the file in **Microsoft Excel (2016 or later)** to ensure compatibility with Power Query and Power Pivot.  
3. Interact with the **Slicers and Timelines** to filter data dynamically.  
4. Analyze **monthly trends, product performance, and regional sales insights** using Pivot Tables and Charts.  

---

## **Dataset**  
The dataset used in this project consists of **customers record, product details, orders transaction table.** The data was cleaned and transformed using **Power Query**, then modeled with **Power Pivot** for efficient analysis.
